Guide d'utilisation

Commencer

Alpha Insight est un assistant financier intelligent spécialisé dans le marché marocain. Posez vos questions en français, arabe ou anglais et recevez des analyses basées sur des données réelles.

Fonctionnalités

Chat Intelligent

Posez des questions sur les entreprises cotées, les indicateurs macro-économiques et la réglementation financière.

Marché en Direct

Suivez les cours de la Bourse de Casablanca en temps réel avec les variations et volumes.

Ingestion de Documents

Importez vos PDF (rapports annuels, notes d'information) pour enrichir la base de connaissances.

Historique

Retrouvez vos conversations passées dans le panneau latéral gauche.

Comment utiliser

1

Posez une question — Tapez votre question dans la barre en bas et appuyez Entrée ou cliquez sur l'icône d'envoi.

2

Importez un document — Cliquez sur le bouton ou "Ingest Data" pour ajouter un PDF.

3

Consultez le marché — Cliquez sur "Live Market" pour voir les cours BVC en direct.

4

Exportez un rapport — Utilisez le bouton "Export Full Report" sous le chat pour télécharger la conversation en PDF.

Modes de focus

New Chat — Mode général, toutes les sources de données sont interrogées.
Company Analysis — Analyse approfondie d'une entreprise cotée spécifique.
Market Macro — Focus sur les indicateurs macro-économiques du Maroc.

Conseils

  • Soyez précis dans vos questions pour obtenir de meilleures réponses.
  • Utilisez les paramètres pour ajuster la profondeur de recherche.
  • Les documents PDF importés sont automatiquement analysés et indexés.
  • Cliquez sur les sources citées dans les réponses pour voir le PDF original.
